# First Dollar Bank — Static Landing

This repository contains a simple static landing page for First Dollar Bank.

Files:
- index.html — landing page
- style.css — styles

How to run locally:
1. Open index.html in a browser, or run a quick local server:
   - Python: `python3 -m http.server 8080`
   - Node (serve): `npx serve .`

Hosting suggestions: GitHub Pages, Vercel, Netlify.
